# CBZ Viewer 操作説明

## GUI

### 初期操作

起動するとライブラリ画面が表示されます。

ライブラリ上部のパス欄に閲覧したいフォルダを指定してください。

指定方法:

* パス入力
* フォルダ選択ダイアログ
* フォルダのドラッグ＆ドロップ

指定したフォルダ内の本が一覧表示されます。
画像を直下に持つフォルダも本として表示されます。

本をダブルクリックするとビューアが起動します。

### 設定

ライブラリ上部の設定ボタンを押すと、次のメニューが開きます。

* `Preferences...` は設定画面を開きます。
* `Language: EN ⇔ JP` は English / 日本語を切り替えます。
* 区切り線
* `About CBZ Viewer...` はアプリケーション名と現在のVersionを表示します。`GitHub` と `Check for latest version` から、既定のブラウザでGitHubを開けます。

設定画面は Library / Viewer / Performance / External Tools / Web Search の 5 タブです。

言語変更は即時反映され、再起動は不要です。

### ライブラリ設定

ライブラリ タブは 一覧 / カード表示 / 画像フォルダ に分かれています。

* 一覧 はカードサイズとホイール速度を調整します。
* カード表示 は HUD 文字とカード HUD / 選択カード表示の見た目を調整します。
* 画像フォルダ は画像フォルダを本として開くかどうかを切り替えます。

設定変更は即時反映されます。

### Viewer 設定

* 表示 は Viewer 全体の画質を調整します。
* 読書 は既定のページ開きと前回の読書位置から再開を切り替えます。
* 再構築後のアーカイブを別Viewerで開く は既定でOFFです。
  OFF では、現在のViewerは次の本へ移動するだけです。
  ON では、再構築後のアーカイブも別Viewerウィンドウで開きます。

### 外部ツール設定

設定 > 外部ツールでは、3件すべてのツール枠が常に表示され、その場で設定します。各枠には Name、Shortcut、Start mode（Background / Normal）、Executable、Arguments があります。Executable には起動するプログラムを指定します。Arguments の `{path}` は対象本のフルパスに置換されます。各枠の項目を編集または空欄にして、設定するか未使用のままにできます。

Libraryでは本（または選択した本）を右クリックし、外部ツール > 登録済みツールを選びます。Viewerでは外部ツールのツールバー、または登録したショートカットを使います。NameとExecutableが空でないツールだけが起動箇所に表示されます。アプリは設定したExecutableを対象パス付きで起動し、外部ツール自体の提供やインストールは行いません。

### WEB検索設定

WEB検索タブでは、使用するブラウザ（Chrome / Edge / Firefox）と開き方（Tab / New Window）を選択し、最大5件の検索先を登録できます。各検索先には Display と Link を設定します。Display と Link は両方とも空でない必要があり、Link には `%s` を含めます。`%s` は選択した token をURLエンコードした文字列へ置換します。不完全な検索先はtokenメニューに表示されません。有効な検索先が0件でも、フィルタリング、コピー、フィルタリングをクリアは引き続き利用できます。

登録した検索先は、Library と Viewer の共通 filename token メニューから利用できます。filename tokenを選択してから、そのtokenを含む「WEB検索」submenuを開き、目的の検索先を選びます。Library、Library連携Viewer、Standalone Viewer、Detached Viewerのいずれでも利用でき、WEB検索にIPCは不要です。tokenを選択しただけではメニューが開いたままなので、再度右クリックせずにフィルタリング、コピー、WEB検索を続けて実行できます。検索先を選ぶとURLを生成し、指定したTab / New Windowで選択ブラウザを起動した後、メニューを閉じます。CBZ Viewer自身はHTTP通信や検索結果の表示を行わず、外部ブラウザプロセスを起動するだけです。実行されるLinkは `http://` または `https://` のみです。選択ブラウザが利用できない場合もクラッシュせず、検索は開かれません。

### Performance

* L1 VRAM Cache: 先読み・履歴ページのGPU Textureを保持する容量
* L2 RAM Cache: デコード済みRGBAをRAMへ保持する容量。通常時は、次本・前本の先読みがそれぞれこの設定の5%を使用します。
* Background Workers: バックグラウンド処理の並列数
* Danger Zone: 通常のハードウェア基準上限を超えて手入力する設定。隣接本の先読みRAMは隣接本1冊あたり5～30%で設定でき、2ページ保証は別枠です。変更はViewerを次回起動した後に反映されます。

## ライブラリ画面

### 基本操作

| 操作 | 内容 |
| --- | --- |
| ダブルクリック | 本を開く |
| Enter | 本を開く |
| Alt+Enter | 選択した項目のプロパティを表示 |
| Delete | 選択した本を削除 |
| F2 | 名前変更 |
| Ctrl+A | 全選択 |
| Ctrl+C | パスをコピー |
| Ctrl+Wheel Up | サムネイル表示を1段階拡大 |
| Ctrl+Wheel Down | サムネイル表示を1段階縮小 |

### サムネイル表示サイズ

サムネイルの表示幅は 120～660px の範囲を20px刻みで変更できます。既定値は200pxです。

* Library > 一覧 のカードサイズ設定から変更できます。
* ライブラリ上で Ctrl+Wheel Up / Down を使うと、1ノッチごとに20px拡大 / 縮小します。
* Ctrl+Wheelで変更した値は設定へ保存され、次回起動時にも復元されます。
* 通常のWheel操作は従来どおりライブラリの縦スクロールに使用します。
* サムネイル幅そのものを画面幅へ合わせて伸縮せず、余った横幅は左右端と列間の余白へ均等に配分します。
* 列間には既存の最小余白を必ず確保します。最終行の項目数が少ない場合も、上の行と同じ列位置を維持します。

### 動画サムネイルのプレビュー

動画ファイルでは、サムネイルに少しホバーするとプレビューが始まります。

* ファイル名HUD以外の領域にホバーすると、動画の10%～90%を自動プレビューします。
* ファイル名HUD領域にホバーし、左右へ動かすと、同じ10%～90%の範囲をスクラブできます。
* カードHUDを非表示にしていても、下端の同じ領域をスクラブに使用します。
* 自動プレビュー領域とスクラブ領域の間を移動すると、すぐにモードが切り替わります。
* ホバーを外すと通常のサムネイルへ戻ります。

### アニメーションWebPサムネイルのプレビュー

Archive と単体画像のサムネイルに少しホバーすると、先頭画像がアニメーションWebPの場合、そのサムネイルがその場で再生されます。アーカイブでは先頭画像のみを再生します。

* ファイル名HUD以外の領域にホバーすると、アニメーションWebPを自動再生します。
* ファイル名HUD領域にホバーして左右へ動かすと、追加の待ち時間なしで、その位置に対応する静止フレームを表示します。
* 1ページのBookのページがアニメーションWebPの場合も同じ時間軸スクラブを使用します。複数ページのBookではページ方向のスクラブを優先します。
* カードHUDを非表示にしていても、下端の同じ領域をスクラブに使用します。
* 自動プレビュー領域とスクラブ領域の間を移動すると、すぐにモードが切り替わります。
* ホバーを外すと通常のサムネイルへ戻ります。

### 静止画サムネイルのスクラブ

Page Map が利用可能な複数ページの画像本が対象で、Archive、FolderBook、EPUB画像本、RAR/CBR などで Static Scrub を使用できます。複数ページのBookでは、ページがアニメーションWebPでもページ方向のスクラブを優先します。

* ファイル名HUD領域で左右に動かすと、全ページをスクラブできます。
* ポインター位置に対応する1ページをサムネイル上に表示します。
* 自動プレビューは行わず、ホバーした位置をすぐに表示します。
* カードHUDを非表示にしていても、同じ下端の仮想領域をスクラブに使用します。
* スクラブ領域の外へ移動すると、通常サムネイルへ戻ります。
* Page Map がない画像本では Static Scrub の対象外です。

### 検索

検索ボックスから本名による絞り込みができます。

### お気に入り

お気に入り登録した本のみ表示できます。

### 読書状態

未読 / 読書中 / 既読で本を絞り込めます。件数も表示されます。

読書状態はビューアで読んだ結果から自動更新されます。途中で閉じると読書中、最後まで表示して閉じると既読になります。

### 拡張子

ファイルの拡張子でライブラリ項目を絞り込めます。件数も表示され、検索ボックスと併用できます。

### グループ

本を任意のグループへ分類できます。

設定方法は [本のグループ設定](book-groups.md) を参照してください。

### 右クリックメニュー

| 項目 | 内容 |
| --- | --- |
| 開く | 本を開く |
| Explorerで開く | エクスプローラーで表示 |
| お気に入りに追加/削除 | お気に入り切替 |
| グループを設定 | グループ分類 |
| 本固有設定をクリア | 本ごとの表示設定と読書状態を初期化 |
| 名前変更 | 名前変更 |
| コピー | パスをコピー |
| 削除 | 削除 |
| プロパティ | 選択した項目の詳細を表示 |
| 外部ツール | 外部ツール実行 |

FolderBook では `フォルダへ移動` も表示されます。

選択した本体ファイルまたはフォルダは削除され、関連するサムネイル、Page Map、お気に入り、グループも削除されます。

複数選択時は一部の項目が表示されないか、無効になります。

Archiveを1件選択した場合は、共通filename tokenメニューからtokenでフィルタリング、フィルタリングをクリア、コピー、登録したWEB検索先を実行できます。WEB検索先は「WEB検索」submenu内に表示されます。tokenを選択しただけではメニューは閉じず、フィルタリング、フィルタリングをクリア、コピー、WEB検索を実行すると閉じます。Libraryの「フィルタリングをクリア」はキーワードを空にし、既存のフィルタを更新対象としてdirtyにします。

## ビューア画面

Viewerのfilename tokenメニューでも、Libraryと同じtoken選択と操作を利用できます。`XXXでフィルタリング` は既存のViewer→LibraryフィルタIPCがあるLibrary連携 / Snapshot Viewerでのみ有効です。「フィルタリングをクリア」は常に有効で、IPCがある場合はLibraryへ対称な最小clear要求を送り、Standalone / Detached / CLIでは安全に何もしません。コピーとWEB検索はIPC不要で、クリップボードまたは外部ブラウザを使います。

### ページ移動

| 操作 | 内容 |
| --- | --- |
| ← / → / A / D | ページ移動 |
| PageDown | 次ページ |
| PageUp | 前ページ |
| Wheel Down | 次ページ |
| Wheel Up | 前ページ |
| Home | 先頭 |
| End | 最後 |

右開き / 左開きの設定により、← → と A D の進行方向は反転します。

### 本移動

| 操作 | 内容 |
| --- | --- |
| ↑ / ↓ | 本移動 |
| W / S | 本移動 |

ライブラリで表示されている本順序に従って前後へ移動します。

本と画像フォルダが混在していても同じ順序で移動できます。

### 表示

| 操作 | 内容 |
| --- | --- |
| F11 | フルスクリーン切替 |
| Space | スライドショー開始/停止 |
| ESC | 閉じる（フルスクリーン時は解除） |

### 本管理

| 操作 | 内容 |
| --- | --- |
| Delete | 現在の本を削除 |

画像フォルダを削除すると、フォルダ全体が削除されます。

### ページ範囲削除とアーカイブ再構築

この操作はアーカイブ本を再構築します。
Library から開いたアーカイブ本でのみ使用できます。
FolderBook、EPUB、ImageFile は対象外です。

すべての画像ページは削除できません。
失敗時は選択範囲を維持したまま再実行できます。

操作:

* `M`
  未選択なら、表示中ページ集合の小さいページを Start にします。
  Start のみなら、表示中ページ集合の大きいページを End にします。
  Start と End があるなら、表示中ページ集合の小さいページから再選択します。
* `Esc`
  範囲選択中は Clear Mark します。
  それ以外は既存動作のままです。
* `Delete`
  Start と End があるときは Delete Pages を開きます。
  それ以外は現在の本を削除します。
* 右クリック
  クリックした画像ページを Start / End に使います。
* 左下ヘルプ
  範囲選択中は `Range: S=...` / `Range: S=... E=...` を表示します。

### ツールバー

ツールバーから以下を操作できます。

* お気に入り
* 表示モード（AUTO / 単ページ / 見開き）
* ページ開き
* 表紙ブランク
* 画質
* スライドショー
* フルスクリーン
* 外部ツール

アニメーションWebPはアニメーションとして再生されます。見開き表示にも対応しています。

### ページ開き

右開き / 左開きでページ送りの向きが変わります。

設定の優先順位は次の通りです。

* 本別設定
* 未設定ならグローバル既定値

この設定は、左右キー、進捗バー、前後本カードの向きにも反映されます。

### 画質

4 モードがあります。

| 設定 | 意味 |
| --- | --- |
| 速度優先 | 生成速度を優先します |
| 標準 | 速度と画質の均衡を取ります |
| 画質優先 | 実表示サイズに対する高品質処理を優先します |
| 原寸優先 | 元画像解像度を安全上限内で維持します |

原寸優先では、読み込み時間と RAM / GPU メモリ使用量が増え、キャッシュ可能なページ数が減ります。

アニメーション画像には一部の画質処理が適用されません。

### 言語設定

English / 日本語 を切り替えられます。

既定は English です。

変更は即時反映されます。

## CUI（コマンドライン）

### 本を開く

```cmd
cbz-viewer.exe "C:\path\to\sample.cbz"
```

### 画像フォルダを開く

```cmd
cbz-viewer.exe "C:\path\to\books"
```

### 画像ファイルを開く

```cmd
cbz-viewer.exe "C:\path\to\page01.jpg"
```

対応画像ファイルから起動した場合は、親フォルダを画像本として開き、指定画像から表示を開始します。

### 複数起動

複数のビューアを同時に起動できます。

ウィンドウタイトルには現在開いている本のファイル名が表示されます。

* JPEG
* PNG
* WebP（静止画 / アニメーション）
* AVIF（.avif / .avifs）
* BMP
* TIFF
* GIF
